# CHEMAGE MVP 검증 기록

검증일: 2026-10-22 (한국 시간)

## 실행 결과

- Node.js 22.23.2, Windows, Chromium 기반 브라우저.
- `npm.cmd test`: **3개 파일, 48개 테스트 통과**, 실패 0.
- `npm.cmd run build`: **TypeScript 검사 및 Vite 프로덕션 빌드 통과**.
- 개발 서버 `http://localhost:5177/`: HTTP 200.
- 브라우저 콘솔: 확인 시점 warning/error 0.

## 테스트 구성

- 전투 엔진 40개: 정확한 다중집합 판정, 소모·무효 입력·초과 보관·정제, 기본 행동, 8개 마법, 상태 지속시간과 비중첩, 직접·지속·반사 피해, 예고와 실제 행동, 보스 페이즈, 7개 보상, 전투 전환·승패·도감 저장.
- React 상호작용 7개: 조합·사용·해금, 빠른 중복 클릭, 직접 원소 버리기, 취소·정제 전환, 도움말, 최종 승리 및 패배 후 재시작, 보상 선택.
- 전체 모험 시뮬레이션 1개: seed 1~200, 원소·능력치 조작 없이 진행. **197회 클리어 / 3회 패배 / 중단 0**, 평균 26.74턴. 전 레시피를 아는 간단한 탐욕 전략의 결과이며 사람의 승률 추정이 아님.

## 실제 브라우저 확인

- 메뉴에서 시작 → 원소 선택 → H₂O 조합 → 13 피해와 3개 원소 소모 → 다음 턴 원소 보존.
- 이어서 H₂O → 젖음 상태에 NaCl → 적 격파 및 체력 회복 → 3개 보상 표시.
- 정밀 합성 선택 → 두 번째 전투 진입, 새 원소 8개 및 유지된 체력 확인.
- 390×844: 문서 높이 844px, 체력바 하단 824.67px. 튜토리얼을 포함해 한 화면에 배치.
- 430×932: 문서 높이 932px, 체력바 하단 887px. 가로 넘침 없음.
- 320×568: 가로 넘침 없음, 원소 버튼 너비 최소 52.53px. 필요한 부분은 세로 스크롤.
- 원본 도트 스프라이트, 레시피 강조, 상태 뱃지, 해금 알림을 육안 확인.

## 남은 검증 범위

- 실제 iOS Safari 및 Android 기기에서의 터치·브라우저별 실측은 하지 않음.
- 자동 플레이 결과가 처음 플레이하는 사람의 난이도나 재미를 대신하지 않으므로, 사용자 플레이 피드백을 통한 추가 밸런스 조정 가능.
- 배포 및 오디오는 이번 결과에 포함하지 않음.
