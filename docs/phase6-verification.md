## 구현과 규칙 결정

- 마법 13종, 반응 3종, 원소 6종, 기존 적·5전투·2회 시전·상성·공통 보호막·ZERO·순수 턴 종료를 보존했습니다. 새 콘텐츠·서버·의존 라이브러리를 추가하지 않았습니다.
- `src/data/hints.ts`: 물질의 특징은 각 물질에 맞게 작성하고, 원소 종류·총수와 정확한 조합은 실제 마법 레시피에서 생성합니다. Fe/C는 게임 조합 타일 1개입니다. HCl의 염화 수소/수용액 염산, FeCl₂·FeO의 (II), NaOH·CH₄·H₂O₂·NaCl의 명칭을 구분합니다.
- 기존 도감 미발견 항목에서 0→1→2→3단계로 무료 공개합니다. 기본 목록에는 이름과 화학식을 노출하지 않습니다. 발견한 마법은 기존 상세 정보를 유지합니다. 힌트를 전부 읽어도 발견되지 않습니다.
- 반응은 원리→관련 마법→정확한 순서로 공개합니다. 2단계 관련 마법은 발견한 경우만 화학식을 표시하며 미발견은 ??? 버튼으로 해당 마법 힌트에 연결합니다. 목록으로 돌아가면 반응 힌트 단계가 유지됩니다.
- 중화는 같은 턴 HCl 다음 NaOH, 연소는 O₂ 강화가 남은 같은 전투에서 CH₄(다른 공격이 먼저 사용되면 강화 소비), 결정은 H₂O 젖음이 남은 같은 턴/바로 다음 턴의 NaCl을 안내합니다. 반응 성공 조건·젖음 만료를 엔진 테스트로 대조했습니다. 결정 연계는 판타지임을 명시했습니다.
- `src/game/hints.ts`: 손패 수량을 검사하고 미발견이며 만들 수 있는 마법 중 힌트가 덜 공개된 하나를 추천합니다. 전구는 기존 빠른 조합 영역에만 표시하고 애니메이션 중에는 숨깁니다. 선택한 슬롯·가방·턴·마력은 그대로 유지합니다.
- PHASE 5 실제 구현은 조합 완성 시 발견을 저장했으나, PHASE 6의 명시적 요구에 맞춰 **실제 시전 시 발견**으로 변경했습니다. 화학 연구도 새 마법 시전/새 반응 성공 시 발동하며 전투당 1회 제한을 유지합니다. 새 마법 표시를 시전 연출에 연결했습니다. 기존 저장된 발견은 취소하지 않습니다.
- 원소 공명은 기존 1→1.5→2배 가중치·전체 확률 정규화를 유지합니다. 게임 상태 `pendingResonance`에 최근 선택 원소 하나를 예약하고 다음 전투 시작 시 2개를 확정한 뒤 예약을 null로 소비합니다. 시작 손패 5개는 **확정 2 + 무작위 3**입니다. 별도 2개를 더하지 않습니다. 첫 플레이어 턴은 기존 시작 5개로 시작하고 이후 턴은 기본 3개(+기존 추가 채집 보상)를 지급합니다.
- 공명 원소 선택은 아직 보상 적용이 아닙니다. 관련 마법과 확률 변화·즉시 효과를 본 뒤 확정해야 다음 전투로 넘어갑니다. 확정 전 변경 가능, 확정 연타 방지, 최대 가중치 원소는 선택 불가입니다. 관련 미발견 마법은 이름·화학식을 숨깁니다.
- 발견 키 `chemage.discoveries.v1`, 반응 키 `chemage.reactions.v1` 유지. 새 `chemage.hints.v1`은 알려진 ID와 정수 0~3만 복구합니다. 저장 오류에서는 세션 내 힌트를 유지하고 게임을 계속합니다.

## 실제 브라우저 검증

인앱 Chromium의 실제 앱과 개발 전용 QA를 구분하여 확인했습니다. 사용자가 플레이 중인 localhost 탭과 별도의 127.0.0.1 탭을 사용했습니다.

- 실제 앱의 기존 마법 8개가 그대로 유지됨. 미발견 FeCl₂ 항목을 1→2→3 단계로 공개하고 새로고침 후 3단계 복구. 공개만으로는 8/13이 변하지 않음.
- 미발견 중화 반응 2단계에 ??? 관련 마법 버튼 표시 → NaOH의 별도 단계 힌트로 이동 → 반응 힌트로 복귀 → 3단계에서 정확한 순서 공개. 반응 기록은 0/3 유지.
- 실제 손패 H/H/O/Fe/Cl에서 기존 추천 3개와 전구 하나 표시. H 하나 선택 후 힌트 확인/닫기에도 슬롯 H, 가방 5개, 턴 1, 마법 2회, 마력 0 유지. 이후 HCl을 직접 조합·시전하고 도감 9/13 해금 확인.
- 보상 QA는 실제 Rewards와 chooseReward 엔진을 사용합니다. Fe의 발견된 Fe·FeO는 표시하고 FeCl₂는 ???로 숨김. Fe→Cl→Fe 변경은 전투를 시작하지 않으며 최종 확정 뒤 보스전 5/5, 손패 Fe/Fe/O/O/O 총 5개 확인.
- 320 / 390 / 430px에서 힌트·전투·공명 화면 확인. 실제 전투 320px에서 scrollWidth=clientWidth=320. 힌트/보상은 세로 스크롤바 유무에 따라 콘텐츠 305/375/415px 또는 전체 너비이며 가로 넘침 없음. 힌트 글과 공명 확정 버튼에 접근 가능.
