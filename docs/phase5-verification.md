# CHEMAGE PHASE 5 검증 보고서

검증일: 2026-10-25 (KST). 이 보고서는 로컬 PHASE 5 구현에 대한 기록입니다. 공개 GitHub Pages는 PHASE 4이며 PHASE 5는 아직 배포하지 않았습니다.

## 구현

- 기존 React + TypeScript + Vite, 1대1 세로 전투, 2회 시전, 원소 6종, 5전투, 속성 상성, ZERO BURST와 공통 보호막을 보존했습니다.
- H₂ / NaOH / FeCl₂를 추가해 총 13개 마법으로 확장했습니다. 원소 순서와 무관한 레시피와 정확한 원소 소모를 검증했습니다.
- H₂의 4, NaOH의 5는 보호막 전용 추가 피해로 먼저 처리합니다. 남는 추가 피해는 HP로 넘치지 않습니다. 일반 피해에는 기존 강화·상성·방어력 계산을 적용합니다.
- FeCl₂는 금속 피해 16, 이번 적 행동의 각 직접 타격 −3입니다. 중첩하지 않고 갱신하며 방어·충전 행동이 끝나도 만료합니다.
- 같은 턴 HCl → NaOH 실제 시전은 중화 피해 8과 보호막 6을 한 번 지급합니다. 추가 피해는 중립이며 적 방어력·보호막의 영향을 받습니다. 반응 보호막은 고정 6으로 기존 방어 강화 보상의 마법 보호막 +3과 구분했습니다.
- O₂ → CH₄는 기존 강화 +10만 적용합니다. 강화가 남아 있으면 다음 턴에도 가능합니다. H₂O → NaCl은 기존 +4와 젖음 소모를 유지합니다. 반응 알림 프레임에서도 소모된 강화·젖음을 제거했습니다.
- 조합 영역의 조건부 안내, 짧은 반응식과 발견 연출, 기존 도감 안의 반응 탭을 추가했습니다. 중화·연소의 실제 화학 개념과 게임 효과를 구분하고 결정 연계는 판타지로 명시했습니다.
- 신규 크리스탈 미니언과 코러시브 젤의 픽셀 스프라이트, 투사체, 결정 보호막·연계 효과를 제작했습니다. 일반 적 5종 중 중복 없이 3종 → 기존 정예 → 보스입니다. 첫 모험만 슬라임으로 시작합니다.
- 젤의 취약 +3은 사용자 선택에 따라 충전 동안 유지하고 다음 직접 공격 행동 후 소모합니다. 강타 기본 피해는 14이며 취약 상태에서는 17로 예고하고 실제 적용합니다. 중첩하지 않습니다. 강타는 수치 임계값과 별개로 위험 행동으로 지정해 붉은 경고를 표시합니다. 기존 적 수치·패턴은 높이지 않았습니다.
- 반응 증폭 +3 최대 2회, 화학 연구 새 발견 시 +20 마력 전투당 1회, 원소 공명 가중치 1.5배 → 2배와 확률 재정규화를 구현했습니다. 공명 원소 선택은 기존 보상 화면 안에서 처리합니다.
- 기존 화학식 완성 시 발견 규칙을 유지하므로 화학 연구도 새 화학식을 완성한 순간 발동할 수 있습니다. 반응 발견은 실제 성공 때만 발생합니다. 두 발견이 같은 전투에 생겨도 연구 보상은 1회입니다.
- 기존 마법 저장 키를 보존하고 반응 기록만 별도 키로 저장합니다. 재도전·새 전투에서 임시 효과, 반응 순서, 연구 발동 여부를 올바르게 초기화합니다.

## 전략별 200회, 총 1,400회 자동 플레이

시드 1~200. 각 실행은 독립적인 미발견 기록과 무작위 일반 적 경로로 시작하며 정책은 모든 레시피를 알고 있습니다. 실제 엔진으로 한 턴 내 최대 2회 행동을 비교하며 미래 난수는 읽지 않습니다. 후보 평가의 미래 원소 추정에는 고정 난수 0.5를 사용합니다. 자세한 원시 결과는 phase5-balance.json입니다.

| 전략 | 승리 / 200 | 승률 | 중화 / 연소 / 결정 발동 |
| --- | ---: | ---: | ---: |
| 공격 피해 우선 | 158 | 79% | 28 / 13 / 246 |
| 상성 피해 우선 | 156 | 78% | 54 / 13 / 180 |
| 방어 마법 + ZERO만 | 3 | 1.5% | 0 / 0 / 0 |
| 공격·방어 혼합 | 160 | 80% | 62 / 14 / 174 |
| 반응 우선 | 162 | 81% | 85 / 18 / 184 |
| 원소 절약 | 184 | 92% | 60 / 16 / 192 |
| 마력 가치 우선 | 163 | 81.5% | 63 / 13 / 172 |

모든 전략에서 진행 정지 0회. 반응 우선 정책이 항상 최선이 되지는 않았습니다. 같은 H/H/O/Na/Cl 손패에서 중화는 피해 24와 보호막 6, 물→소금은 피해 28을 제공해 방어와 피해 사이의 선택이 생기는 것도 검증했습니다.

해석 제한: 이 정책들은 제한된 탐색과 임의 가중치를 사용한 회귀 검사이며 인간의 승률·난이도·재미를 보장하지 않습니다. 공격·상성 정책도 방어 마법을 허용하고, 방어 전용 정책은 극단적인 제한 정책입니다. 마력 우선 정책이 반드시 ZERO를 더 많이 사용하지도 않습니다. 원소 절약 정책의 높은 성과는 추가 플레이테스트 대상입니다. 연소 강화는 반응 우선에서도 200회 중 총 18번으로 드뭅니다. 7개 재료 요구에 비해 활용도가 충분한지는 인간 플레이로 더 확인해야 하며, 모든 전략의 균형이 완성됐다고 주장하지 않습니다.

## 실제 브라우저 확인

- 인앱 Chromium에서 개발용 고정 시나리오와 실제 모험 화면을 각각 확인했습니다. QA는 실제 엔진·UI를 사용하되 손패를 고정하며 배포 빌드에는 포함하지 않습니다.
- 320 / 390 / 430px: 문서 scrollWidth와 clientWidth 일치. QA 외부 스크롤바 15px를 제외한 콘텐츠 너비는 각각 305 / 375 / 415px입니다. 반응식, 적 HP, 버튼에 가로 넘침이 없습니다.
- 중화 발견·반응식 1회 표시, 연소 강화, 미니언 보호막 파괴, 공명 원소 선택 후 다음 전투, 반응 도감 탭을 확인했습니다.
- 젤 취약 부여 → 충전 → 강타 예고 17 → 실제 HP 53에서 36으로 감소를 확인했습니다. FeCl₂는 골렘에 금속 약점 피해 24, 공격 예고 24에서 21로 감소했습니다.
- 1.5배속과 움직임 줄이기를 함께 켜고 중화의 12개 이벤트 재생 완료: 적 HP 16, 내 HP 58, 다음 턴 마법 2회. 콘솔 오류·경고 없음.
- 실제 모험에서는 기존 도감 8개가 13개 중 8개로 보존되고 무작위 첫 적이 등장했습니다. CO₂와 HCl의 두 번 시전, 자동 적 행동과 다음 플레이어 턴을 확인했습니다.
