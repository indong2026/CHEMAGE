# PHASE 4 검증 보고서

검증일: 2026-10-25. 대상은 chemage 로컬 PHASE 4 개발본입니다. 공개 GitHub Pages는 PHASE 3.1이며 PHASE 4를 게시하지 않았습니다.

## 구현

- 여섯 속성과 여섯 비중립 관계를 별도 데이터로 정의. 마법 10개·적 5개에 속성 지정.
- 직접 마법의 강화·연계 후 상성/버림/방어력/보호막/HP 순서 적용. ZERO·지속·반사 제외. 예측과 실제 결과 동일.
- 무료 기본 방어 제거. 턴 종료는 추가 보호막 없이 적 행동으로 진행. 보상은 보호막 마법마다 +3, 중복 보상 합산.
- 기존 공통 보호막 중첩과 13번 규칙 보존. CO₂ 감소와 C 반사는 행동당 한 번, 연속 타격 사이 잔량 유지, 모든 타격 후 반사, 행동 종료 후 만료.
- 비틀 6+6, 정예 7+7+7, 골렘 2페이즈 10+10. 스피릿 충전→20, 골렘 충전→28. 예고 데이터와 실제 공격 데이터 동일.
- 적 속성·방어력·보호막·상태 지속시간을 적 HP에, 내 보호막·강화를 내 HP에 배치. 0 수치 숨김, 터치 설명.
- 상성 문구와 추가 충돌, 차분한 저항 피해, 흡수량, BLOCK, SHIELD BREAK, 방어력 감소 피드백.
- 도감 저장 키와 ID 유지. 기존 화학 사실 보존, 게임 상성과 구분.

## 4전략 × 200시드 자동 플레이

| 전략 | 승리 | 승률 | 유리한 상성 타격 | 저항 타격 | 진행 정지 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 공격 중심 | 158 / 200 | 79% | 619 | 905 | 0 |
| 상성 활용 | 157 / 200 | 78.5% | 750 | 732 | 0 |
| 보호막 중심 | 2 / 200 | 1% | 0 | 0 | 0 |
| 공격·방어 혼합 | 165 / 200 | 82.5% | 716 | 740 | 0 |

시드 1~200, 모든 레시피를 아는 정책, 최대 320명령, 한 플레이어 턴 안에서만 탐색합니다. 공격/상성 정책은 같은 HP 가중치 1.2로 방어 마법도 허용합니다. 공격 정책은 실제 HP 피해를 배율로 나눈 근사 기본 피해를 평가하고 상성 정책은 실제 피해를 평가합니다. 혼합은 HP 보존 가중치 2.5. 보호막 정책은 방어·강화와 ZERO만 사용합니다. 보상 우선순위는 동일합니다. 숨은 실제 미래 추첨은 읽지 않습니다.

상성 활용은 유리한 타격을 늘리고 저항 타격을 줄였지만 **이번 자동 플레이에서는 전체 승률 이점이 입증되지 않았습니다**. 1회 행동 탐색, 근사 기본 피해 평가, 초기 원소/보상 운의 한계가 있습니다. 보호막만 반복하는 전략의 과도한 우세는 관찰되지 않았습니다. 공격만 허용했던 초기 정책은 방어 없이 버티지 못했으므로 최종 비교의 공격 중심 정책에는 낮은 가중치로 방어를 허용했습니다. 초기 측정은 phase4-balance-initial.json에 별도로 보존했습니다.

저항은 면역이 아닌 0.75배이며 모든 속성에 ZERO·중립 마법·넘침 마력 대안이 있습니다. 800회에서 무한 진행은 없었지만 모든 불리한 손패가 승리 가능하다는 보장은 하지 않습니다. 적 HP/방어력이나 전체 공격력을 승률에 맞춰 일괄 증가시키지 않았습니다. 자동 승률은 사람의 재미·난이도 평가가 아닙니다.

## 실제 브라우저 확인

Codex 내장 Chromium, 로컬 Vite 서버와 실제 UI를 사용했습니다. 일부 희귀 상황은 실제 엔진과 Battle을 사용하는 개발용 QA 고정 시나리오로 검증했습니다.

- **390×844 실제 게임**: 화면/문서 너비 390, 높이 844, 내부 game-shell scrollHeight=clientHeight=844. 하단 버튼까지 스크롤 없이 조작. 추천 H₂O 선택→예상13→실제 적48→35, 마법1/2, 첫 시전 후 새 턴 배너 없음.
- 순수 턴 종료→ENEMY TURN→플레이어60→52, 다음 턴2·마법2/2. 무료 보호막 없이 원소 유지·추가 지급. 1.5배속 실제 H₂O에서35→22, 이후 입력 복구.
- **320px QA**: 실제 콘텐츠305px(개발 QA 컨트롤로 외부 세로 스크롤바15px), scrollWidth=clientWidth=305. 전투 버튼/적 HUD의 가로 넘침 없음. 물→화염 피해19와 경고 확인.
- **430×932 QA**: 콘텐츠415px, 가로 넘침 없음, 게임 내부scrollHeight=clientHeight=932. 화염→화염 피해15와 저항 피드백 확인.
- 부식/방어막 시나리오: 방어력5→2, 보호막3 흡수, 실제 HP60→58, 유리한 상성 및 SHIELD BREAK를 서로 구분.
- 정예3연타: Fe+Fe 총32, 타격마다32→25→18→11과 BLOCK·1/3·2/3·3/3 표시. 종료 후 잔여11이 한 번 소멸. 적 턴 하나와 다음 YOUR TURN 확인.
