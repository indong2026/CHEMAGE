# PHASE 9 — 전투 UX 및 신규 발견 경험 검증

검증일: 2026-10-27. 로컬 PHASE 8 최신 소스에서 수정했습니다. **PHASE 9는 배포하지 않았습니다.** 이전 PHASE 8 배포 체크아웃 `releases/phase8`은 깨끗한 상태를 유지합니다.

## 구현

### 화면 안정성과 재구성

재구성 안내 패널을 제거했습니다. 기존 가방 제목을 선택 안내로 바꾸고, 기존 턴 종료/ZERO 버튼 공간을 취소/확정으로 전환합니다. 가방·카드의 DOM 위치와 순서를 유지하고 조합 입력은 선택 모드에서 잠급니다. 확정 전 소모하지 않으며 같은 ID 한 장만 교체하는 기존 엔진과 연속 입력 잠금을 사용합니다. 가방 제목 40px, 발동 버튼 55px, 하단 조작 48px를 고정하여 상태 문구 길이에 따른 밀림을 막았습니다.

기존 페이지와 게임 영역의 세로 스크롤은 유지합니다. 확장 가방 내부 스크롤도 유지합니다. 안내와 발견 연출은 화면 상단 오버레이이며 safe-area를 고려합니다. 세로 공간을 추가하는 튜토리얼 줄은 제거했습니다.

### 마법 역할과 반응

역할 분류는 `presentation/ux.ts`에서 19종을 검증합니다. 공격은 #C85D4C/검, 방어는 #347FB9/방패, 보조는 #27896F/반짝임입니다. H₂S는 공격색에 방패를 함께 표시합니다. 실제 엔진의 `previewSpell` → `availableReaction` 판정을 재사용해 연계 가능할 때만 #E9B94E/연결 아이콘으로 바꿉니다. O₂의 다음 턴 유지, 젖음 만료, 중화/암모늄염의 같은 턴 순서 조건을 그대로 사용합니다.

반응 연출은 황금색 파티클과 반응명, 기존 반응식, 추가 피해/보호막 정보를 표시합니다. 일반 주문의 속성 이펙트와 ZERO의 보라색은 유지합니다. 보스의 기존 2페이즈 알림에는 연속 공격 주의를 덧붙였습니다.

### 발견과 NEW

현재 소스는 PHASE 6부터 **실제 마법 시전 성공 시** 발견을 기록합니다. 이 판정을 바꾸지 않고 엔진의 `freshSpell`/`freshReaction` 이벤트에 연출을 연결했습니다. PHASE 5의 과거 조합 즉시 발견 규칙으로 되돌리지 않았습니다. 힌트 공개만으로는 발견하지 않습니다.

NEW DISCOVERY와 NEW REACTION은 같은 카드 체계를 쓰되 황금색/청록색과 아이콘으로 구분합니다. 화학식·이름·도감 등록 문구를 표시하고 기본 1.8초 후 사라집니다. 동시에 발생하면 화학식 다음 반응 순서입니다. 알림은 전투 입력을 잠그지 않고 닫을 수 있습니다.

`chemage.unread.v1`은 기존 발견 저장 키와 별개입니다. 키가 없는 기존 플레이어의 항목을 새 항목으로 만들지 않습니다. 새 발견만 추가하고, 전체 마법의 상세 확인이나 원소별 상세 진입으로 NEW를 해제합니다. 반응 기록의 상세 확인도 같은 방식입니다. 원소별 목록은 같은 마법 ID의 상태를 공유합니다. 새로고침은 NEW 상태를 복원하되 발견 연출을 재생하지 않습니다.

### 가이드와 알림 순서

기존 전투 타임라인은 턴 배너·마법/적 행동·반응·ZERO/재구성 준비를 재생합니다. 별도 정보 큐 `useNotices`는 이 타임라인과 모달·재구성 선택 중에는 표시를 중단합니다. 전투 연출이 끝난 뒤 발견 → 반응 발견 → 진입 안내 → 일반 가이드 순으로 하나씩 보여줍니다. 큐는 식별자로 중복을 막고, 다음 행동 중에는 숨겼다가 이어서 표시합니다. 실제 상태 계산과 분리되어 있으며 안내 완료로 전투를 진행하지 않습니다. CSS animationend에 의존하지 않고 타이머로 종료합니다. 시각/음향 콜백 실패도 전투 잠금을 영구 유지시키지 않도록 처리했습니다.

신규 플레이어는 기존 첫 슬라임 전투에서 조합, 최대 두 번 시전, 남은 원소 보관과 턴 종료를 배웁니다. 첫 시전 이후에는 더 이상 최초 조합 안내를 대기열에 남기지 않으며, 다음 턴으로 넘어가면 한 번 더 시전하라는 오래된 안내를 제거합니다. 보호막·유리한 상성·반응·재구성·ZERO를 처음 경험할 때 짧게 안내합니다. 준비 완료 알림 자체는 기존 이벤트를 유지하고 첫 설명만 추가합니다.

`chemage.guides.v1`에 안내 진행과 건너뛰기를 저장합니다. 기존 모험/발견 기록이 있는 플레이어는 최초 조작 안내를 자동 재생하지 않습니다. 도움말의 기본 전투 가이드에서 언제든 다시 읽을 수 있습니다. 가이드는 건너뛰거나 개별 확인할 수 있습니다. 일반 진입 안내는 모험의 첫 일반 전투에만, 정예/보스 안내는 해당 진입 시 짧게 표시합니다.

스마트 가이드는 19종 실제 레시피를 검사합니다. 미발견이 있어도 조합 가능한 경우에는 불가 안내를 띄우지 않으며, 화학식을 노출하지 않습니다. 시전 완료/입력 잠금/선택 중/재구성 모드에는 표시하지 않습니다. 조합이 없으면 보관 후 턴 종료를 안내하고, 재구성·ZERO가 가능하면 함께 제시합니다. 이벤트를 매 렌더링마다 생성하지 않고 현재 상태에서 도출하며, 조건이 해소되면 바로 없어집니다.

## 모바일 레이아웃 실측

개발 전용 `qa/phase9.html`에서 실제 Battle·엔진·알림 큐를 사용했습니다. 재구성 진입/선택/취소/실행 완료, 일반 가이드/발견 알림 전후를 각각 비교했습니다. `getBoundingClientRect`로 가방·카드·발동 버튼·하단 조작·플레이어 체력의 위치와 크기를 측정하고, 문서·게임 영역·가방 내부 scrollTop을 함께 기록했습니다.

| 크기 | 가방/카드 위치·크기 변화 | 발동/하단 버튼 위치 변화 | 스크롤 변화 | 가로 넘침 |
| --- | --- | --- | --- | --- |
| 320×568 | 0px | 0px | 0px | 없음 |
| 360×800 | 0px | 0px | 0px | 없음 |
| 390×844 | 0px | 0px | 0px | 없음 |
| 430×932 | 0px | 0px | 0px | 없음 |

위 네 크기의 총 24개 전후 비교가 일치했습니다. 320×568에서는 게임 영역을 184px 내려둔 상태에서도 재구성 전후 스크롤을 유지했습니다. 추가로 390×844의 14칸 확장 가방을 내부에서 약 53.33px 스크롤한 뒤 진입/선택/취소/실행 완료를 비교했고 모두 같은 scrollTop을 유지했습니다. [전체 좌표 원본](phase9-layout-measurements.json).

공격 H₂O, 방어 Fe, 보조 O₂, 혼합 H₂S 버튼의 실제 계산 스타일은 각각 지정한 RGB 값과 일치하고 높이는 모두 55px였습니다. [역할별 측정](phase9-role-measurements.json). NH₃ 다음 HCl은 황금색 RGB(233,185,78), 예상 피해 12로 표시됐습니다.
