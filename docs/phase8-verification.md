# PHASE 8 — 원소별 화학식 도감 검증

2026-10-26, 로컬 최신 PHASE 7에서 수정. PHASE 8은 미배포이며 GitHub Pages와 `releases/phase6` 체크아웃은 변경하지 않았습니다.

## 변경 내용

- 기존 `Codex`의 전체 마법/반응 기록 구조에 원소별 보기 탭 추가.
- `ELEMENT_KEYS`에서 8개 선택 버튼 생성, `spellsForElement`가 기존 `SPELLS[].recipe`의 양수 개수로 관련 마법을 자동 필터링. 별도 분류 목록은 저장하지 않음.
- 원소 버튼은 관련 종수, 선택 목록은 한글 이름/기호/발견 비율 표시. 총 발견 수는 고유한 기존 마법 ID를 기준으로 계산.
- 원소별 목록은 기존 카드 디자인의 간결한 요약을 사용. 발견 카드를 누르면 기존 화학 사실·게임 효과 상세 화면, 미발견 카드를 누르면 기존 `HintDetail`로 연결.
- 미발견 카드는 `???`, `미발견 마법`, 픽셀 자물쇠만 표시. 접근성 이름도 기록 번호와 힌트 안내만 사용하며 화학식·이름을 숨김. 3단계 힌트를 이미 열어도 목록은 실제 발견 전까지 숨김 유지.
- 목록으로 돌아올 때 원소 선택 유지. 원소 버튼은 4열 × 2행, 기존 원소 색상과 카드 스타일 사용.
- 저장 키와 데이터, 원소 8종/마법 19종/반응 4종, 전투·보상·재구성·공명·ZERO BURST·확률·밸런스 유지. 의존성 추가/업데이트 없음.
