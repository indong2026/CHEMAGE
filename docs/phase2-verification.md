## 재현 가능한 밸런스 비교

각 전략에 seed 1–200을 사용한 **총 1,000개 모험**. 모든 조합을 아는 탐욕 에이전트이며 사람의 승률을 뜻하지 않습니다. 실제 엔진, 실제 원소 추첨과 보상, 실제 5전투를 사용하고 HP·자원·드롭을 보정하지 않습니다. 선택에 따라 RNG 소비 경로가 달라지므로 같은 시드라도 후반 원소가 완전히 같지는 않습니다. 각 실행은 최대 180스텝이며 제한에 걸린 실행은 0건입니다.

| --- | ---: | ---: | ---: |

실패한 모험도 평균 행동 수에 포함합니다. 방어 포함 행동은 기본 방어와 방어 마법을 모두 셉니다. 전략별 보상 우선순위는 동일하고, 단일 마법 전략은 수동 방출을 쓰지 않으므로 연쇄 수만 바꾼 완전한 대조 실험은 아닙니다.

- 연쇄 전략의 3개 마법이 실제 모두 발동한 행동: **942회**. 세 마법 자체의 평균 직접 피해 **24.07**. 수동 방출·ZERO·잔류·반사까지 포함한 해당 행동 평균 피해 **37.24**. 방어/강화 마법도 세 마법에 포함합니다.
- 첫 행동에서 적이 행동하기 전에 처치: **36 / 1,000전투 진입 = 3.6%**.
- ZERO: **1,716회**, 모험당 **8.58회**, 전체 행동의 **40.0%**. 같은 전투에서 최장 **5행동 연속** 발생했습니다. 추가 채집 보상이 중첩되고 모든 레시피를 활용하면 반복 발동이 가능한 상태입니다. 무한 발동은 아니지만 ZERO의 희소성이 높다고 평가할 수는 없습니다. 명세의 발동 조건·피해량과 기존 보상 누적 규칙은 유지했습니다.
- 연쇄 전략의 스테이지별 평균 행동 수: **3.69 / 3.34 / 3.03 / 5.88 / 5.53**. 패배 전 행동도 포함합니다. 마지막 두 전투가 초반보다 짧아지지 않았습니다.
- 방어 제외 전략은 **158 → 6클리어**로 감소했습니다. 최소한 이 정책과 시드 집합에서는 방어 마법을 조합할 가치가 분명합니다.
- 모든 전략에서 정지 0건. 기본 공격 전략도 초과 원소 자동 방출을 정상 처리했습니다.

초기 Phase II 수치에서는 연쇄 전략이 200/200으로 클리어했습니다. HP를 추가로 늘리지 않고 정예 공격을 16/22, 골렘 1페이즈를 16/충전/24/방어, 2페이즈를 26/18/20/방어로 조정했습니다. 강공격과 페이즈 변경은 사전에 표시됩니다. 변경 전 측정은 `phase2-balance-initial.json`, 최종 측정은 `phase2-balance.json`입니다.
