## 엔진 처리 기준

재구성은 마법과 별도 액션입니다. 상태 변경 전에 전투 상태·유효한 카드 ID·게이지 100·시전 가능한 플레이어 상태·리비전을 확인합니다. 선택한 카드 한 장만 새로운 ID의 카드로 교체하며 나머지 카드와 조합 슬롯은 유지합니다. 소모된 카드의 조합 선택만 해제합니다. 이미 처리한 액션이나 오래된 리비전은 재실행되지 않습니다. UI의 동기 잠금도 연속 터치와 애니메이션 중 마법/턴 종료 충돌을 막습니다.

순수 엔진은 적 행동 전체를 한 번에 판정하고 UI가 프레임을 순서대로 재생합니다. 따라서 외부에서 조작 가능한 중간 적 턴 상태를 만들지 않고, 재생 중 입력을 잠급니다. 게이지는 적 행동 완료 후 살아 있는 다음 플레이어 턴으로 진행할 때 한 번만 35를 더합니다. 다중 타격도 한 번, 방어·충전·대기도 한 번입니다. 적 행동 없이 승리하거나, 지속 피해·반사·패배로 전투가 끝나 다음 플레이어 턴이 없으면 충전하지 않습니다. 전투 간에는 유지하고 새 모험만 0으로 초기화합니다.

재구성 추첨은 소모 원소를 제외한 7종에 동일한 확률을 적용하며 공명 가중치와 일반 획득 가중치를 참조하지 않습니다. 주입 가능한 RNG로 재현할 수 있습니다. 원소 개수·마력·시전 횟수·턴·보호막·반응 시전 이력·마법 통계는 바꾸지 않습니다.

NH₃의 피해 감소는 다음 적 행동의 각 직접 공격에 적용하고 행동 종료 때 지웁니다. FeCl₂와 함께 있으면 더 강한 3만 적용하며 합산하지 않습니다. NO₂와 H₂O₂의 지속 피해는 기존 비중첩 규칙을 이어 마지막 시전의 피해량과 2회 지속으로 갱신합니다. H₂S는 공격과 보호막을 모두 실제 피해 미리보기에 반영합니다. 암모늄염 추가 피해는 기존 중화 추가 타격처럼 중립·방어력·적 보호막 판정을 거칩니다.

재구성 준비 알림은 게이지가 처음 100에 도달하는 이벤트로 생성하며, 플레이어 턴 배너와 ZERO 준비 알림 뒤에 순서대로 재생합니다. 준비 알림은 기본 1.2초, 변환은 0.85초입니다. 1.5배속 및 움직임 줄이기를 반영하고 상태 변경은 애니메이션 성공 여부에 의존하지 않습니다.

## 확률 조정 근거

처음에는 제안값 H28/O24/C15/Na8/Cl8/Fe5/N6/S6을 사용했습니다. 기존 확률과 고정 시드 손패를 비교했을 때 NaCl/HCl 감소가 커서 다음 값으로 조정했습니다. 공격력이나 적 패턴을 바꾸지는 않았습니다.

| 원소 | 제안 | 최종 |
| --- | ---: | ---: |
| H | 28% | 29% |
| O | 24% | 23% |
| C | 15% | 13% |
| Na | 8% | 9% |
| Cl | 8% | 9% |
| Fe | 5% | 5% |
| N | 6% | 6% |
| S | 6% | 6% |
| 합계 | 100% | 100% |

8개 무작위 손패 10,000회에서 각 마법을 적어도 한 번 만들 수 있었던 비율입니다. 공명·튜토리얼 확정 지급·재구성 없이 분포만 비교합니다.

| 마법 | 기존 6종 | 최초 제안 8종 | 최종 8종 |

NaCl/HCl 감소는 완화했지만 CH₄의 조합 빈도는 여전히 낮습니다. 12개 손패에서는 CH₄가 기존 43.51% 대비 35.24%입니다. 최종 5개 손패에서 어떤 마법도 없는 경우는 0.71%였으며, 이는 공격 마법이 반드시 있다는 뜻은 아닙니다. 신규 원소를 희석하거나 레시피를 바꿔 억지로 이전 빈도에 맞추지는 않았습니다.

## 재구성 사용 전후 200시드 비교

같은 mixed 전략과 시드 1–200을 사용합니다. 재구성은 현재 가방에서 7개 결과의 **조합 가능한 서로 다른 레시피 수 증가 기대값**이 가장 큰 원소를 고르며, 기대값이 양수일 때 사용합니다. 미래 RNG를 읽지 않습니다. 재구성 RNG는 원소 지급 RNG와 별도 시드 흐름으로 설정하여 재추첨 횟수만으로 후속 지급이 밀리는 영향을 줄였습니다. 모든 레시피를 아는 자동 전략이므로 실제 신규 플레이어 승률로 해석하면 안 됩니다.

| 지표 | 재구성 미사용 | 재구성 사용 |
| --- | ---: | ---: |
| 승리 | 151/200 (75.5%) | 153/200 (76.5%) |
| 판단 시점당 조합 가능한 마법 평균 | 2.627 | 2.806 |
| 조합 불가 턴 종료 횟수 | 903 | 797 |
| 판단 기회 대비 조합 불가 턴 종료 | 10.25% | 9.32% |
| 신규 마법 시전 | 1,159/7,242 (16.00%) | 1,179/7,105 (16.59%) |
| 3라운드 이상 사용 불가 원소 관측 비율 | 658/13,109 (5.02%) | 311/12,318 (2.52%) |
| 재구성 사용 | 0 | 1,039 |
| 재구성으로 이전에 불가능한 마법 가능 | 해당 없음 | 624/1,039 (60.06%) |

재구성 순간 만들 수 있는 마법 평균은 3.375 → 4.284였습니다. 승률 차이는 +1%p로 작아 통계적으로 확정적인 승률 개선이라고 주장하지 않습니다. 원소 교체가 항상 좋은 결과를 보장하지 않으며, 조합 기회 확대와 오래 남는 원소 감소가 이번 시뮬레이션에서 더 뚜렷했습니다. 관측 비율은 같은 카드의 여러 라운드 관측을 포함하므로 고유 카드 비율이 아닙니다.

[상세 결과](phase7-reconstruction-balance.json). 신규 마법은 사용 전략에서 N₂ 150, NH₃ 67, NO₂ 288, H₂S 273, SO₂ 228, FeS 173회 시전됐습니다.

### 남은 밸런스 한계

7개 전략 승리는 attack 145, affinity 143, shield 6, mixed 153, reaction 154, stockpile 174, burst 159 / 각 200회였습니다. 비축 전략과 방어 전용 전략의 격차는 남아 있습니다. mixed 재구성 사용 전략에서도 C가 전체 시전의 약 24.1%로 높고 CH₄/FeCl₂ 사용은 드뭅니다. 신규 마법 추가만으로 기존 전략 우세가 모두 해소되지는 않았습니다.

기존 공명 보스 비교에서는 확정 지급 미사용 128/200, 사용 172/200이었습니다. 이 비교는 재구성 전략을 사용하지 않으며 철 공명의 즉시 지급이 강한 기존 경향을 보여 줍니다. 이번 범위에서 보상이나 보스를 임의로 약화/강화하지 않았습니다. 신규 마법의 수치는 제안 그대로 두고, 실제 사람의 장기 플레이 피드백이 필요하다는 한계를 남깁니다.

## 실제 브라우저 검증
