# CHEMAGE · PHASE 3.1

React + TypeScript + Vite 기반 한국어 모바일 화학 마법 턴제 게임. 원소 선택 → 화학식 발견 → 즉시 시전 → 적의 반응을 중심으로 전투와 화면을 재구성했습니다.

## 실행

Node.js 22.12 이상. 검증 환경은 Windows / Node 22.23.2입니다.

```powershell
cd CHEMAGE
npm.cmd install      # 최초 설치 시
npm.cmd run dev      # http://localhost:5177/
npm.cmd test         # 128개 테스트, 4전략 × 200시드 포함
npm.cmd run build    # TypeScript 검사 + dist 생성
npm.cmd run preview  # 프로덕션 미리보기, 4177 포트
```

Windows 경로의 ^ 문자 문제를 피하기 위해 npm 스크립트는 Node 진입점을 직접 실행합니다. 신규 라이브러리, 서버, 데이터베이스를 추가하지 않았습니다. **PHASE 3.1 + 보호막 13번 규칙 배포 소스입니다.**

공개 게임: https://indong2026.github.io/CHEMAGE/ — PHASE 3.1. main 브랜치에 push하면 자동 테스트와 빌드 후 GitHub Pages로 배포합니다. 이전 PHASE 3은 Git 이력에 보존되어 있습니다.

## 새 전투 규칙

- 매 전투 원소 5개로 시작. 첫 슬라임은 H 2개와 O 1개를 보장합니다. 이후 턴마다 기본 3개를 받습니다.
- 최대 5개를 선택하여 화학식을 완성하고 즉시 시전합니다. 한 턴에 마법 2회. 첫 시전 후 계속 조합할 수 있고, 두 번째 시전 후 적이 한 번 행동합니다.
- “방어하고 턴 종료” 하나로 남은 시전을 포기하고 기본 보호막 8(강화 보상 반영)을 더한 뒤 적 턴으로 진행합니다.
- 가방 기본 용량 12개. 기존 원소는 보존하며 새 지급분 중 들어갈 공간이 없는 원소만 개당 마력 15로 변환합니다.
- 마법 시전마다 마력 +10, 최대 100. 마력 100에서 ZERO BURST를 직접 누르면 마력 100을 소비하고 피해 30을 주며 턴을 끝냅니다. 방어력은 무시하고 적 보호막은 적용합니다. 처치 시 적 행동은 생략합니다. 마력은 다음 전투로 이어집니다.
- 화학식 완성 즉시 도감에 등록됩니다. 발견했고 현재 만들 수 있는 마법만 최대 3개 추천합니다. 추천을 누르면 원소만 선택하며 자동 시전하지 않습니다.
- H₂O → NaCl의 젖음 연계, O₂ → 공격 강화, HCl → 방어력 감소, CO₂ → 공격으로 방어와 공격을 함께 사용합니다. Fe(+16), CO₂(+12), C(+10), 기본 방어(+8)의 보호막은 모두 합산합니다. 같은 마법도 중첩하며 한 턴의 마법 사용은 최대 2회입니다.
- 마법 10종, 적 5종, 보상, 도감, 엔딩을 유지합니다. 기존 기본 공격·원소 방출·정제·예약 연쇄 UI와 관련 보상은 제거했습니다.

## 판정과 화면

전투 엔진은 한 명령의 결과와 프레임을 한 번 계산합니다. UI는 해당 프레임을 순서대로 재생하며 발사 시 HP를 유지하고 명중 시 HP와 피해 숫자를 함께 변경합니다. 첫 마법 후에는 상태 지속시간, 적 행동, 원소 지급이 진행되지 않습니다.

턴 종료 시 지속 피해 → 기존 적 보호막 만료 → 예고된 적 행동 → 반사 → 승패 판정 → 상태 지속시간 처리 → 보스 페이즈/다음 예고 → 원소 지급 순서입니다. 지속·반사 피해는 방어력과 보호막을 모두 무시합니다. 새로 부여한 젖음과 부식은 같은 턴 경계에서 감소하지 않습니다. 동시 사망은 플레이어 패배가 우선입니다.

상단 적 체력과 행동 예고, 중앙 전투와 5개 조합 슬롯, 하단 가방과 플레이어 체력·마력·행동 버튼을 배치했습니다. 상태 아이콘과 마법 효과를 눌렀을 때만 상세 설명이 열립니다. 긴 전투 로그와 피해 예측 패널은 없습니다. 설정에서 효과음, 1.0/1.5배속, 움직임 줄이기, 턴 알림 간소화를 변경할 수 있습니다. 일반 연출은 넘길 수 있고 턴 배너·준비 알림 중에는 입력이 잠깁니다. 마법 발동 버튼에 실제 HP 피해와 방어막 흡수량 또는 보호막 증가량을 표시합니다.

YOUR TURN / ENEMY TURN은 실제 턴 경계에서만 표시합니다. ZERO BURST 준비 알림은 충전마다 한 번이며 적 공격과 겹치지 않게 순서대로 재생합니다. 강공격 경고와 처치 연출은 기존 전투 영역을 재사용합니다.

보호막 피해 순서: 직접 공격 확정 → 첫 직접 화염에 CO₂ 감소 최대 5 → 공통 보호막 흡수 → 초과 HP 피해 → 모든 타격 후 C 반사 3 → 적 행동 종료 시 보호막 및 임시 방어 효과 제거. CO₂ 감소와 반사는 각각 적 행동당 한 번이며 같은 마법을 두 번 사용해도 특수 효과는 중복되지 않습니다. 다중 타격은 보호막 잔량을 이어 쓰도록 지원하되 기존 적 패턴은 변경하지 않았습니다. 대기·충전·방어 행동과 전투 종료에도 보호막이 만료됩니다.

모험 진행과 설정은 새로고침 시 초기화됩니다. 발견한 마법 ID만 chemage.discoveries.v1 localStorage에 저장합니다. 저장 제한 또는 오디오 미지원 환경에서도 게임 진행은 가능합니다.
