# CHEMAGE · PHASE 6

React + TypeScript + Vite 기반 모바일 세로형 화학 마법 턴제 게임. 총 13개 마법, 3개 반응 연계, 5전투를 갖춘 게임입니다. 기존 전투 규칙을 유지하면서 3단계 연구 힌트와 원소 공명의 즉시 효과를 추가했습니다.

## 실행과 배포 상태

Node.js 22.12 이상. Windows / Node 22.23.2에서 검증했습니다.

```powershell
npm.cmd install      # 최초 설치 시
npm.cmd run dev      # http://localhost:5177/
npm.cmd test         # 241개 검사, 1,400회 모험 + 400회 보스 비교 포함
npm.cmd run build    # TypeScript 검사 + 프로덕션 dist
npm.cmd run preview  # http://localhost:4177/
```

Windows 경로의 ^ 문자 때문에 npm 스크립트는 Node 진입점을 직접 실행합니다. 새 라이브러리, 서버, DB는 추가하지 않았습니다.

- 이 폴더: PHASE 5 콘텐츠와 PHASE 6 연구 힌트·원소 공명 개선을 포함한 배포 소스입니다.
- [공개 게임](https://indong2026.github.io/CHEMAGE/): GitHub Pages에서 제공합니다.
- 로컬 배포 소스: `releases/phase6` (6.0.0, 2026-10-26).
- [배포 Actions](https://github.com/indong2026/CHEMAGE/actions/workflows/pages.yml): Linux 테스트·빌드 성공 후 Pages에 게시합니다. 최신 실행에서 실제 배포 상태를 확인할 수 있습니다.

## 전투 규칙

- 한 턴에 마법 최대 2회. 첫 시전 후 계속 조합하고 두 번째 시전 뒤 적이 한 번 행동합니다.
- **턴 종료**는 남은 시전을 포기합니다. 무료 보호막·회복·원소 소모가 없고 이미 시전한 보호막과 특수 효과는 적 행동까지 유지됩니다.
- Fe 16, CO₂ 12, C 10 보호막을 하나의 수치로 합산합니다. 방어 강화 보상은 모든 보호막 마법에 +3이며 중복 보상도 합산합니다.
- 적 직접 피해 → CO₂ 화염 감소 최대 5 → 공통 보호막 → 초과 HP 피해 → 모든 타격 후 C 반사 3 → 남은 보호막과 임시 방어 효과 만료. 화염 감소와 반사는 각각 적 행동당 한 번입니다. 공격 사이에는 보호막을 유지하며 방어·충전·대기에도 행동 종료 시 만료합니다. 동시 사망은 플레이어 패배 우선입니다.
- 원소 5개로 전투 시작, 매 턴 기본 3개 획득, 가방 12개. 기존 원소를 보존하고 초과 지급분만 개당 마력 15로 변환합니다.
- 시전마다 마력 +10. ZERO BURST는 100 소모, 피해 30, 방어력 무시·적 보호막 적용, 턴 종료. 상성은 적용하지 않습니다.
- 발견했고 만들 수 있는 마법만 최대 3개 추천합니다. 추천은 원소 선택만 하며 직접 발동합니다. 발견 기록의 저장 키와 마법 ID를 유지했습니다.

## 마법 속성과 계산

| 속성 | 마법 |
| --- | --- |
| 물 | H₂O |
| 화염 | CH₄ |
| 금속 | FeO, Fe, FeCl₂ |
| 부식 | HCl |
| 결정 | NaCl |
| 중립 | H₂O₂, O₂, CO₂, C, H₂, NaOH |

물→화염, 부식→금속, 금속→결정은 1.5배. 화염→화염, 결정→금속, 물→결정은 0.75배. 나머지는 1배입니다. 이 관계는 판타지 전투 규칙이며 실제 화학 법칙을 뜻하지 않습니다.

직접 공격 마법은 **기본 피해 + 마법 강화 + 공격 강화 + 연계 → 상성 → 소수점 버림 → 유효 방어력 → 적 보호막 → HP** 순서입니다. NaCl의 방어력 5 관통은 유지합니다. ZERO, 지속 피해, 반사에는 상성을 적용하지 않습니다. 예상 HP 피해와 보호막 흡수량은 실제 엔진 계산을 재사용합니다.

슬라임은 중립, 비틀과 정예는 금속, 스피릿은 화염, 골렘은 결정입니다. 비틀 6×2, 정예 7×3, 골렘 2페이즈 10×2를 타격마다 재생합니다. 스피릿은 충전 뒤 20, 골렘은 충전 뒤 28을 예고합니다.

## 반응과 보상

- H₂ 피해 7 + 보호막 전용 4, NaOH 피해 9 + 보호막 전용 5. 전용 피해를 먼저 처리하고 남는 수치는 HP로 넘치지 않습니다.
- FeCl₂ 피해 16, 이번 적 행동의 각 직접 타격 −3. 같은 효과는 중첩하지 않습니다.
- 같은 턴 HCl → NaOH는 추가 중립 피해 8 + 보호막 6. O₂ → CH₄는 기존 +10, H₂O → NaCl은 기존 젖음 +4를 한 번 적용합니다.
- 일반 적 5종 중 서로 다른 3종 → 정예 → 골렘. 첫 모험만 슬라임으로 시작합니다.
- 크리스탈 미니언은 결정 보호막을 사용합니다. 코러시브 젤의 취약은 충전 동안 유지되고 다음 직접 공격 행동에 +3을 적용한 후 사라집니다.
- 반응 증폭은 중화 추가 피해 +3, 최대 2회. 화학 연구는 전투 중 새 발견 때 마력 +20, 전투당 1회. 원소 공명은 선택 원소 가중치 1.5배 → 2배로 누적하고 확률을 재정규화합니다.

## PHASE 6 연구 힌트와 공명

- 미발견 마법 13종과 반응 3종에 3단계 무료 힌트를 제공합니다. 도감에서 원할 때 하나씩 공개하고 공개 단계를 저장합니다.
- 마법 힌트는 특징 → 필요한 원소 종류·총수 → 정확한 조합, 반응 힌트는 원리 → 관련 마법 → 정확한 순서입니다. 미발견 관련 마법은 ???로 표시하고 해당 힌트로 이동합니다.
- 마법은 **실제로 시전할 때** 발견됩니다. PHASE 5의 조합 즉시 해금을 변경했습니다. 기존 발견 기록은 그대로 인정하며 화학 연구의 +20 마력도 실제 새 마법 시전/새 반응 성공 때 적용합니다.
- 현재 손패로 만들 수 있는 미발견 마법이 있으면 추천 영역에 전구 하나를 표시합니다. 덜 공개된 힌트를 우선하며, 선택 슬롯·원소·턴에는 영향을 주지 않습니다.
- 공명 선택은 원소 선택 → 관련 마법·확률·확정 지급 미리보기 → 최종 확정입니다. 확정 전에는 선택을 바꿀 수 있습니다.
- 다음 전투 시작 손패는 선택 원소 2개 + 무작위 3개, 총 5개입니다. 예약은 시작 때 한 번 소비하며 이후 턴 지급은 기존 기본 3개입니다. 지속 가중치는 모험 종료까지 유지됩니다.

## 전투 화면

적 HP 근처에 속성·약점·저항과 회색 방어력·파란 보호막·상태 지속시간을 표시합니다. 내 보호막 총합과 강화는 내 HP 근처에 표시합니다. 0인 상태는 숨기고 아이콘을 누르면 설명을 엽니다.

명중 시 실제 HP 피해, 보호막 흡수량, 방어력 변화, 상성 문구, SHIELD BREAK를 구분합니다. 턴 배너·ZERO 준비 알림·적 행동은 기존 순서 관리기를 사용합니다. 1.0/1.5배속, 움직임 줄이기, 배너 간소화는 규칙 계산에 영향을 주지 않습니다.

도감의 화학 사실과 게임 설정은 분리해 표시합니다. 모험 진행과 설정은 새로고침 시 초기화되며 발견한 마법은 기존 `chemage.discoveries.v1`, 반응은 별도 `chemage.reactions.v1`에 저장됩니다. 힌트 단계는 `chemage.hints.v1`에 독립 저장합니다. 첫 모험 여부는 `chemage.adventure-started.v1`에 저장하며 기존 마법 기록도 이전 플레이의 근거로 사용합니다.
