# CHEMAGE · PHASE 4

React + TypeScript + Vite 기반 모바일 세로형 화학 마법 턴제 게임. 기존 10개 마법과 5전투를 유지하면서 속성 상성, 방어 판단, 연속 공격과 전투 정보 표시를 개선했습니다.

## 실행과 배포 상태

Node.js 22.12 이상. Windows / Node 22.23.2에서 검증했습니다.

```powershell
npm.cmd install      # 최초 설치 시
npm.cmd run dev      # http://localhost:5177/
npm.cmd test         # 164개 검사, 4전략 × 200시드 포함
npm.cmd run build    # TypeScript 검사 + 프로덕션 dist
npm.cmd run preview  # http://localhost:4177/
```

Windows 경로의 ^ 문자 때문에 npm 스크립트는 Node 진입점을 직접 실행합니다. 새 라이브러리, 서버, DB는 추가하지 않았습니다.

[공개 게임](https://indong2026.github.io/CHEMAGE/) · PHASE 4 배포 소스입니다. main 브랜치에 푸시하면 GitHub Actions가 테스트·빌드 후 Pages에 게시합니다. 배포 성공 여부는 [Actions](https://github.com/indong2026/CHEMAGE/actions)에서 확인할 수 있습니다.

## 전투 규칙

- 한 턴에 마법 최대 2회. 첫 시전 후 계속 조합하고 두 번째 시전 뒤 적이 한 번 행동합니다.
- **턴 종료**는 남은 시전을 포기합니다. 무료 보호막·회복·원소 소모가 없고 이미 시전한 보호막과 특수 효과는 적 행동까지 유지됩니다.
- Fe 16, CO₂ 12, C 10 보호막을 하나의 수치로 합산합니다. 방어 강화 보상은 모든 보호막 마법에 +3이며 중복 보상도 합산합니다.
- 적 직접 피해 → CO₂ 화염 감소 최대 5 → 공통 보호막 → 초과 HP 피해 → 모든 타격 후 C 반사 3 → 남은 보호막과 임시 방어 효과 만료. 화염 감소와 반사는 각각 적 행동당 한 번입니다. 공격 사이에는 보호막을 유지하며 방어·충전·대기에도 행동 종료 시 만료합니다. 동시 사망은 플레이어 패배 우선입니다.
- 원소 5개로 전투 시작, 매 턴 기본 3개 획득, 가방 12개. 기존 원소를 보존하고 초과 지급분만 개당 마력 15로 변환합니다.
- 시전마다 마력 +10. ZERO BURST는 100 소모, 피해 30, 방어력 무시·적 보호막 적용, 턴 종료. 상성은 적용하지 않습니다.
- 발견했고 만들 수 있는 마법만 최대 3개 추천합니다. 추천은 원소 선택만 하며 직접 발동합니다. 발견 기록의 저장 키와 마법 ID를 유지했습니다.

## 마법 속성과 계산

| 속성 | 마법 |
| --- | --- |
| 물 | H₂O |
| 화염 | CH₄ |
| 금속 | FeO, Fe |
| 부식 | HCl |
| 결정 | NaCl |
| 중립 | H₂O₂, O₂, CO₂, C |

물→화염, 부식→금속, 금속→결정은 1.5배. 화염→화염, 결정→금속, 물→결정은 0.75배. 나머지는 1배입니다. 이 관계는 판타지 전투 규칙이며 실제 화학 법칙을 뜻하지 않습니다.

직접 공격 마법은 **기본 피해 + 마법 강화 + 공격 강화 + 연계 → 상성 → 소수점 버림 → 유효 방어력 → 적 보호막 → HP** 순서입니다. NaCl의 방어력 5 관통은 유지합니다. ZERO, 지속 피해, 반사에는 상성을 적용하지 않습니다. 예상 HP 피해와 보호막 흡수량은 실제 엔진 계산을 재사용합니다.

슬라임은 중립, 비틀과 정예는 금속, 스피릿은 화염, 골렘은 결정입니다. 비틀 6×2, 정예 7×3, 골렘 2페이즈 10×2를 타격마다 재생합니다. 스피릿은 충전 뒤 20, 골렘은 충전 뒤 28을 예고합니다.

## 전투 화면

적 HP 근처에 속성·약점·저항과 회색 방어력·파란 보호막·상태 지속시간을 표시합니다. 내 보호막 총합과 강화는 내 HP 근처에 표시합니다. 0인 상태는 숨기고 아이콘을 누르면 설명을 엽니다.

명중 시 실제 HP 피해, 보호막 흡수량, 방어력 변화, 상성 문구, SHIELD BREAK를 구분합니다. 턴 배너·ZERO 준비 알림·적 행동은 기존 순서 관리기를 사용합니다. 1.0/1.5배속, 움직임 줄이기, 배너 간소화는 규칙 계산에 영향을 주지 않습니다.

도감의 화학 사실과 게임 설정은 분리해 표시합니다. 모험 진행과 설정은 새로고침 시 초기화되며 발견한 마법만 `chemage.discoveries.v1`에 저장됩니다.
